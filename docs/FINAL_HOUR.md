# Final-hour scope

## Product promise

**Save your attention. Make meaningful connections.**

**An agent-to-agent network, built around people.**

Approved copy and product intent: [PRODUCT_CONTEXT.md](PRODUCT_CONTEXT.md).

The agent reads for you, discovers relevant people, checks fit with their agents,
and brings back only decisions or conversations worth your attention.

## Finish these, preserve existing work

1. Reliable independent model turns and visible A2A exchanges.
2. A concise personal attention brief: decisions, missing information, useful
   updates and handoffs. Keep the full transcript available behind each item.
3. Clear live/rehearsal/source-replay labels and no real-community writes.
4. Frontend teammate owns polish; backend owns data, routing and validations.
5. Verify, commit and push each meaningful update; freeze interfaces for demo.

This hour does not add a new social network, authentication platform, wallet,
cross-community protocol or live posting integration. Existing modules stay intact.
The live community source is a bounded read-only snapshot, not an always-on bot.
