What runs on this site?

ExperienceWhat you are seeing
Recorded model runsTwo genuine historical model runs about fictional profiles; eight recorded calls. No new inference.
Interactive rehearsalThe existing deterministic agent workflow, adapted to run in your browser. Requests, clarification, approval and handoff remain interactive.
Spider extractionLocal name, topic and time-pattern extraction. The animation is a replay of extracted mentions, not model reasoning.
Community40 fictional profiles. Different skills, goals, availability and evidence produce different outcomes.

No sign-in or API key is needed. No paid model calls occur. Your rehearsal stays in this browser tab and does not change other visitors' data. The member switcher is a demonstration control, not authentication.

Explore further

  • Start a request: choose speaker or collaborator, edit scope and topics, then use Offline rehearsal. Live model execution is disabled.
  • Your attention: choose Offline rehearsal for your new decisions or Recorded model runs for historical outcomes.
  • Try different boundaries: unavailable members decline; missing evidence or unknown availability may require more information. The workflow does not invent agreement.
  • Members: inspect profiles and evidence, or add a fictional demo profile. Changes affect only this session.
  • Repeat: the fixed repeatable demo bypasses normal duplicate-contact suppression while keeping your history.
  • Spider shortcuts: Space pauses, R replays, F enters immersive mode, Esc returns. Export saves local extraction results as JSON.

Restores the initial fictional community in this tab. Your current rehearsal and test messages will be cleared.

Implementation and boundaries

The local development edition uses independent model calls, signed agent events, an attention API, SQLite persistence and isolated historical source replay. This public edition uses the same frontend and deterministic rehearsal logic, with per-tab browser storage. New browser rehearsal events are unsigned.

Real Discord messages, source profiles, private notes and signing keys are excluded. This is a working prototype demonstration, not a deployed multi-user network or a claim of autonomous community participation.
